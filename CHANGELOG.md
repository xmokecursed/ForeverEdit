# Changelog

## 1.0 - 2026-07-25

Initial release.

* Visual drag-and-drop layout editing
* Hide, pin, and inline text editing
* Full visual style editor (colors, fonts, spacing, layout, position)
* Multi-select for batch edits
* Undo/redo
* Per-site and per-URL-pattern customization
* Export/import backups
* Chrome, Brave, Edge, Opera, and Firefox support
